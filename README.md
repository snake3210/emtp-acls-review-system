# 台灣急診醫學會 (TSEM) 108–114 年度 EMT-P 最終筆試（ACLS 專項）視覺化戰情複習系統

一套專為台灣高級救護技術員（EMT-P）甄試筆試打造的 **ACLS 專項視覺化複習系統**，收錄 108 至 114 年度（共 7 年 700 題）中所有與 **ACLS 核心演算法、12 導程與心律判讀、急性冠心症（ACS）、心搏停止（OHCA / ECPR / BLS）、心搏過緩/過速、ROSC 復甦後照護（TTM / EtCO2 圖譜）、核心急救藥物與 5H5T** 相關之 **104 道精選歷屆試題**。

## ✨ 系統四大核心特色

1. **📊 六大領域弱點雷達與多維度過濾器**
   - 即時統計 `核心藥物與5H5T (37題)`、`ACS與12導程 (25題)`、`心搏停止 (16題)`、`ROSC照護 (15題)`、`心搏過速 (9題)`、`心搏過緩 (2題)` 完成度與正確率（低於 70% 自動亮起紅/橘色弱點警示）。
   - 支援篩選：`未作答`、`❌ 答錯題庫`、`⭐ 觀念模糊`、`📈 心電圖/圖譜判讀題 (23題)`、`⚖️ 歷年送分/多解爭議題 (9題)`、各年度切換與即時關鍵字搜尋。

2. **📈 23 張真實考卷心電圖 ＆ EtCO2 圖譜高畫質檢視器**
   - 使用 PyMuPDF 自官方考卷無損裁切 23 張心電圖與生理波形圖。
   - 支援全螢幕放大檢視（Lightbox）、**手機/平板雙指無段縮放（Pinch-to-Zoom）** 與 **一鍵 200% 倍率切換**，題幹零劇透還原真實考場。

3. **🧠 視覺化演算法決策路徑 ＆ 防混淆深度解析**
   - **① ACLS 演算法決策路徑圖 (Algorithm Flowchart)**：將臨床情境拆解為「初步評估 ➔ 心律/血行動力學判讀 ➔ 關鍵處置」節點鏈。
   - **② 易混淆誘答陷阱拆解 (Confusion Trap Alert)**：條列式剖析錯誤選項陷阱，並完整收錄歷年官方送分/多解申訴翻盤關鍵。
   - **③ AHA 2020/2025 最新指引檢核 (Guideline Check)**：對照台灣 EMT-P 教材與最新 AHA 指引差異。

4. **⚡ 考前衝刺「5 大終極易混淆速查表」**
   - 內建分頁式速查抽屜：同步整流焦耳數與頻脈/緩脈處置、12 導程解剖定位與 Sgarbossa 準則、5H5T 超音波與高血鉀三高一低、ROSC 目標與 EtCO2 圖譜、給藥途徑（`NAVEL` / IM / IV / IO）與 ECPR。

## 📦 離線使用方式

- **電腦 / 專案資料夾離線版**：直接雙擊打開 `index.html`（已內建本地 `tailwind.min.js` 與 `acls_data.js`，100% 免連網、免開 Server）。
- **手機 / 平板單一檔案終極獨立版**：只需將 `EMTP_ACLS_終極單一獨立版.html`（單一檔案，已將 23 張心電圖轉為 Base64 內嵌）傳至手機或 iPad 即可離線開啟。
